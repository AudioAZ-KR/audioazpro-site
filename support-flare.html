Flare Tally 연결·문제해결

지원 › Flare Tally 연결·문제해결
제품이 출시 준비 중이라 일부 화면·경로는 베타에서 확정될 수 있습니다. 문제가 지속되면 support@audioazpro.com 으로 문의해 주세요.

1. 구성

  • macOS 호스트 앱 1대 + 카메라마다 스마트폰(브라우저) 1대.
  • 호스트가 ATEM 스위처와 연결되어 PGM/PVW·키어 상태를 각 폰에 전송합니다.

2. ATEM 연결

  • 호스트 앱에 ATEM의 IP 주소를 입력해 연결합니다(같은 네트워크 권장).
  • 지원: Blackmagic ATEM 시리즈(Mini · Mini Pro · Mini Extreme · Constellation 등).
  • 키어(자막·PIP) 온에어까지 탈리에 반영됩니다.

3. 폰 연결 (QR / 방 코드)

  1. 호스트 화면의 방 코드 또는 QR을 카메라 폰으로 스캔·입력합니다.
  2. 같은 Wi-Fi면 오프라인 연결, 인터넷·LTE면 원격 연결이 됩니다.
  3. 연결되면 해당 카메라가 PGM이면 빨강, PVW면 초록으로 표시됩니다.

4. 문제 해결

  • 폰이 연결 안 됨: 방 코드/URL을 정확히 입력했는지, 폰과 호스트가 같은 네트워크(또는 인터넷)에 있는지 확인.
  • 탈리 색이 안 바뀜: 호스트-ATEM 연결 상태와 IP를 확인. 키어 반영은 해당 키어가 온에어일 때 표시됩니다.
  • 원격(LTE)에서 지연/끊김: 네트워크·방화벽 환경에 따라 포트 개방 등 설정이 필요할 수 있습니다.

5. 지원 환경 (베타 확정 예정)

  • 호스트: macOS 앱 (Apple 공증 서명)
  • 카메라 단말: 스마트폰 웹브라우저(별도 설치 불필요)
  • 네트워크: 같은 Wi-Fi 또는 인터넷·LTE
