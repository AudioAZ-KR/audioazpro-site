스위처 연결 방법

지원 › Flare Tally › 스위처 연결 방법
호스트 앱의 '연결 설정' 창에서 브랜드에 맞는 칸만 채우면 됩니다. 화면 그림은 영문 기준입니다.

먼저 — 스캔으로 찾기

대부분은 직접 입력할 필요가 없습니다. 호스트 앱에서 '스캔'을 누르면 USB로 꽂힌 스위처와 네트워크별 검색 버튼이 함께 나옵니다. 찾은 스위처를 고르면 주소와 종류가 자동으로 들어갑니다.

비밀번호를 쓰는 기종(OBS · Roland · AVMatrix · vMix)을 고르면 연결 설정 창이 바로 열립니다. 나중에 다시 열려면 주소 칸 옆 '연결 설정' 버튼을 누르세요.

ATEMOBS StudiovMixRolandAVMatrixOSEE GoStreamTSL UMDUSB 연결

Blackmagic ATEM

포트 9910 고정 · 비밀번호 없음 · Mini · Mini Pro · Mini Extreme · SDI · Television Studio · Constellation

  1. ATEM을 맥과 같은 네트워크에 연결하거나, ATEM Mini 계열은 USB-C로 맥에 바로 꽂습니다.
  2. 호스트 앱에서 '스캔' → 찾은 ATEM을 고릅니다. USB로 꽂았다면 'USB로 연결됨' 칸에 나옵니다.
  3. 직접 넣을 때는 연결 설정 창에 ATEM의 IP만 적습니다. 포트·비밀번호는 없습니다.

ATEM은 주소 한 칸뿐입니다.

키어(자막·PIP)가 온에어면 그 소스도 빨강으로 표시하고, 입력 수에 맞춰 카메라 수가 자동으로 잡힙니다.

OBS Studio (28 이상)

기본 포트 4455 · 비밀번호를 켰다면 필요

  1. OBS에서 '도구 → WebSocket 서버 설정'을 엽니다(영문 Tools → WebSocket Server Settings).
  2. 'WebSocket 서버 사용'에 체크합니다.
  3. '서버 포트'(기본 4455)를 확인합니다. '인증 기능 사용'이 켜져 있으면 '서버 비밀번호'가 필요합니다 — '서버 정보 표시'를 누르면 비밀번호가 보입니다.
  4. 호스트 앱의 연결 설정 창에 OBS가 도는 컴퓨터의 IP·포트·비밀번호를 넣고 저장합니다. 같은 맥에서 OBS를 돌리면 주소는 127.0.0.1 입니다.

OBS의 WebSocket 서버 설정 — 여기의 포트와 비밀번호를 그대로 옮겨 적습니다.

호스트 앱의 OBS 연결 설정 창.

장면 이름의 첫 숫자가 카메라 번호입니다(예: 1 Cam, 카메라 2). 숫자가 없으면 장면 목록 순서를 씁니다. 프로그램 장면이 빨강, 스튜디오 모드의 프리뷰 장면이 초록입니다.

vMix

TCP API 기본 포트 8099 · 비밀번호 없음

  1. vMix가 도는 PC의 IP를 확인합니다.
  2. 그 PC의 방화벽에서 8099 포트가 막혀 있지 않은지 확인합니다.
  3. 호스트 앱의 연결 설정 창에 IP를 넣습니다. 포트를 바꿔 쓴다면 포트 칸에 그 번호를 넣습니다.

vMix는 주소와 포트만 씁니다.

vMix의 입력 번호가 그대로 카메라 번호가 됩니다.

Roland (V-60HD · V-80HD · V-160HD)

웹(Smart Tally) 기본 포트 80 · 웹 인증을 켠 기종만 아이디·비밀번호

  1. 스위처 메뉴의 LAN 설정에서 IP 주소를 확인하고, 맥과 같은 네트워크에 연결합니다.
  2. 스위처의 Smart Tally(탈리 출력) 기능을 켭니다.
  3. 호스트 앱의 연결 설정 창에 IP를 넣습니다. 장비 웹 화면에 로그인을 걸어 두었다면 아이디·비밀번호도 넣습니다.

Roland는 웹 인증을 켠 경우에만 아이디·비밀번호가 필요합니다.

기종과 펌웨어에 따라 지원 범위가 다를 수 있습니다.

AVMatrix (SHARK 시리즈)

장비 웹 로그인 · 기본 포트 80 · 공장 기본 계정 admin / admin

  1. 스위처를 맥과 같은 네트워크에 연결하고 장비 화면에서 IP를 확인합니다.
  2. 브라우저로 그 IP에 들어가 로그인이 되는지 확인합니다(공장 기본값 admin / admin).
  3. 호스트 앱의 연결 설정 창에 IP와 그 계정을 넣습니다. 비밀번호를 바꿨다면 바꾼 값을 넣습니다.

AVMatrix는 아이디와 비밀번호를 함께 씁니다.

OSEE GoStream

기본 포트 19010 · 비밀번호 없음

  1. 스위처 화면의 Setting → Network에서 IP를 확인합니다.
  2. 호스트 앱의 연결 설정 창에 그 IP를 넣습니다.

GoStream은 주소만 넣으면 됩니다.

8-ISO 모델은 4001~4004 입력이 카메라 5~8로 이어집니다.

TSL UMD (Ross · TriCaster · Panasonic · Grass Valley 등)

기본 포트 9000 · 주소 없음 — 스위처가 이 맥으로 보냅니다

  1. 호스트 앱의 연결 설정 창에서 기다릴 포트만 정합니다(기본 9000).
  2. 스위처의 TSL(UMD) 출력 대상을 '이 맥의 IP'와 그 포트로 설정합니다. 호스트 화면 아래쪽에 맥의 IP가 적혀 있습니다.
  3. TSL 3.1 또는 5.0 어느 쪽이든 받습니다.

TSL은 포트 한 칸뿐입니다.

주소(인덱스) 0이 카메라 1, tally1(빨강)이 PGM, tally2(초록)가 PVW입니다.

USB로 꽂은 스위처 (Roland V-1HD 등)

넣을 값 없음 · 케이블만 연결

  1. 스위처를 USB로 맥에 꽂습니다.
  2. 호스트 앱에서 '스캔'을 누르면 'USB로 연결됨' 칸에 그 스위처가 나옵니다. 고르면 끝입니다.

USB로 꽂은 스위처는 넣을 값이 없습니다.

ATEM Mini 계열을 USB-C로 꽂았을 때도 같은 칸에 나옵니다.

연결이 안 될 때

  • '비밀번호가 필요합니다'라고 뜨면 연결 설정 창에서 비밀번호를 넣습니다. OBS는 서버 정보 표시, AVMatrix는 장비 웹 로그인 계정입니다.
  • '스위처 응답 없음'이면 IP와 포트, 그리고 스위처가 맥과 같은 네트워크에 있는지 확인합니다.
  • PC에서 도는 스위처(OBS · vMix)는 그 PC의 방화벽이 포트를 막고 있을 수 있습니다.
  • 스캔에 안 나오면 주소를 직접 넣어 보세요. 다른 네트워크에 있는 장비는 스캔에 안 잡힙니다.
