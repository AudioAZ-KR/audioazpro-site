개인정보처리방침

최종 업데이트: 2026-09-01 · 초안(정식 판매 개시 전 확정)

본 문서는 출시 준비 단계의 초안입니다. 실제 회원가입·결제 개시 시점에 관련 법령(전자상거래법·개인정보보호법 등)에 맞춰 최종본으로 대체됩니다.

1. 수집하는 개인정보

AudioAZ는 서비스 제공을 위해 다음 정보를 수집할 수 있습니다: 이메일 주소, 이름, 결제 관련 정보(결제대행사 경유), 라이선스·기기 활성화 정보, 서비스 이용 기록.

2. 이용 목적

  • 계정 인증 및 라이선스 발급·관리
  • 결제 처리 및 환불
  • 고객 지원 및 공지
  • 서비스 개선 및 부정 이용 방지

3. 보관 및 파기

수집한 정보는 이용 목적 달성 시까지 보관하며, 관련 법령이 정한 기간(전자상거래 기록 등)에 따라 보관 후 안전하게 파기합니다.

4. 제3자 제공·처리위탁

결제 처리(포트원·Paddle 등), 이메일 발송, 클라우드 인프라 등 서비스 운영에 필요한 범위에서 처리위탁할 수 있으며, 위탁 시 관련 사항을 고지합니다.

5. 이용자 권리

이용자는 언제든 본인 정보의 열람·정정·삭제·처리정지를 요청할 수 있습니다. 요청은 support@audioazpro.com 으로 접수합니다.

5-1. Flare Tally 앱(iOS·macOS)이 처리하는 정보

Flare Tally 카메라 탈리 앱은 계정 없이 동작하며 이름·이메일 등 개인정보를 요구하지 않습니다. 실시간 탈리 전달을 위해 다음 정보만 서버(camera-tally.onrender.com)로 전송·일시 보관합니다.

  • 방 코드·카메라 번호 — 어느 방의 어느 카메라에 표시할지 정하기 위해 접속 중에만 사용
  • 기기 식별자(iOS identifierForVendor) — 같은 기기의 중복 알림 등록을 정리하기 위한 익명 식별자. 사용자를 식별하지 않으며 다른 정보와 결합하지 않음
  • 푸시 알림 토큰(Apple APNs) — 앱이 뒤에 있을 때 다이나믹 아일랜드·알림으로 탈리를 갱신하기 위한 토큰. Apple 푸시 서비스로만 전달
  • 서버 왕복 지연(ms) — 호스트 화면의 접속 현황 표시용
  • 알림 설정값(알림·진동·잠금 유지 여부, 앱 언어) — 어떤 알림을 보낼지 정하기 위해 접속 중에만 사용

iOS 앱은 같은 Wi-Fi의 호스트를 찾기 위해 로컬 네트워크 권한을 사용합니다(Bonjour 검색). 이 과정에서 외부로 전송되는 정보는 없습니다.

익명 진단 정보(제품 개선용) — 앱과 호스트는 기본적으로 기기 모델, OS 버전, 앱 버전, 접속 방식(온라인/오프라인), 스위처 종류, 오류 종류(접속 실패·끊김 등)를 익명으로 보냅니다. 기기 식별자는 일부만 해시해 사용하며 이름·계정·이메일·방 코드·IP·위치와 연결하지 않아 특정 개인을 알 수 없습니다. 90일 뒤 자동 삭제되고 제품 개선 외 목적으로 쓰지 않습니다. 앱의 도움말(?) 화면과 호스트 설정의 익명 사용 정보 보내기에서 언제든 끌 수 있습니다.

macOS 호스트 앱은 라이선스 확인을 위해 로그인한 AudioAZ 계정의 인증 토큰과 익명 기기 식별자(하드웨어 UUID의 해시)를 중계 서버로 보내며, 서버는 이를 라이선스 조회에만 사용하고 저장하지 않습니다. 데모 사용 시에는 기기 식별자와 데모 시작 시각만 전송됩니다. 계정 로그인 정보(갱신 토큰)는 사용자의 맥에만 저장되며 비밀번호는 저장하지 않습니다. 스위처 IP 등 설정은 맥에만 저장됩니다.

위 정보는 접속(세션) 중 서버 메모리에만 있으며 접속 종료·앱 종료 시 삭제되고, 별도 저장·분석·광고·추적에 사용하지 않습니다. 카메라 권한은 방 QR 코드를 읽을 때만 사용하며 영상은 저장·전송하지 않습니다.

Flare Tally (iOS/macOS) — English summary: The app needs no account and collects no personal data. To deliver tally in real time it sends only the room code, camera number, an anonymous device identifier (identifierForVendor, used solely to de-duplicate push registrations), the Apple push token, round-trip latency and notification preferences to our relay server (camera-tally.onrender.com). These are kept in server memory only for the duration of the session, are never stored, analysed, sold, or used for tracking or advertising, and are not linked to any identity. The iOS app uses the Local Network permission (Bonjour) only to find a host on the same Wi-Fi; nothing is sent externally for this. Anonymous diagnostics (on by default, switchable off in the app's Help screen and in the host settings): device model, OS version, app version, connection mode, switcher type and error types only, with a partial hash of the device identifier; never linked to a name, account, email, room code, IP or location, deleted after 90 days, and used solely to improve the product. The macOS host app sends the signed-in AudioAZ account token and a hashed, anonymous device identifier to the relay server solely to verify the license (or the demo start time while in demo); the server does not store them. Camera access is used only to scan a room QR code; no video is stored or transmitted. Contact: support@audioazpro.com
