1. 수집하는 개인정보

AudioAZ는 서비스 제공을 위해 아래 정보를 수집합니다. 필수 항목은 해당 서비스 이용에 반드시 필요한 정보이며, 정보주체와 체결한 계약의 이행에 불가피하게 필요한 경우 별도의 동의 없이 수집·이용할 수 있습니다(개인정보 보호법 제15조 제1항 제4호).

  • 회원가입 (필수) — 이메일 주소, 이름
  • 유료 결제 (필수) — 구매자 이름, 휴대폰 번호. 결제대행사(KG이니시스)의 카드 결제 요건상 필수 입력 항목이며, 카드사 본인확인과 결제 결과 안내에 사용됩니다. 카드번호·유효기간·비밀번호 등 결제수단 정보는 결제대행사가 직접 처리하며 AudioAZ는 저장하지 않습니다.
  • 라이선스 이용 — 라이선스 키, 기기 활성화 정보(기기 이름·익명 기기 식별자), 서비스 이용 기록
  • 해외(달러) 결제 — 이메일 주소와 주문번호를 해외 결제 판매대행사 Lemon Squeezy에 전달합니다. 이름·카드 정보·청구 국가 등은 Lemon Squeezy가 결제 화면에서 직접 수집하며 AudioAZ는 받지 않습니다.
  • 문의 — 이메일 주소, 문의 유형·제목·내용, 첨부파일(선택)
  • 베타 테스터 신청 — 이름, 이메일 주소, 사용 장비 등 메모(선택)
  • 동의 기록 — 회원가입·베타 신청 시 이용약관·개인정보 수집·이용에 동의한 시각
  • 자동 수집 — 접속 IP 주소, 브라우저·기기 정보, 접속 일시(서버 접속 기록). 로그인 상태 등은 브라우저 저장소에 보관됩니다(7항 참조).

구매자 이름·휴대폰 번호는 다음 결제 시 자동 입력되도록 회원 계정에 저장되며, 내 계정에서 언제든 수정하거나 삭제를 요청할 수 있습니다.

2. 이용 목적

  • 계정 인증 및 라이선스 발급·관리
  • 결제 처리 및 환불
  • 고객 지원 및 공지
  • 서비스 개선 및 부정 이용 방지

2-1. 구매자 휴대폰 번호를 수집하는 이유

유료 결제 시 구매자 휴대폰 번호를 받는 것은 아래 목적 때문이며, 그 밖의 목적으로는 이용하지 않습니다.

  • 카드 결제 요청에 필요한 필수 항목입니다. 결제대행사인 KG이니시스의 카드 결제 규격이 구매자 휴대폰 번호를 필수 입력값으로 정하고 있어, 이 값이 없으면 결제창 자체가 열리지 않습니다. AudioAZ가 임의로 정한 항목이 아닙니다.
  • 카드사 본인확인 및 결제 결과 통지. 카드사·결제대행사가 결제 승인·취소 사실을 구매자에게 알리는 데 사용합니다.
  • 주문 처리 중 문제가 생겼을 때의 연락. 결제는 승인됐으나 라이선스 키 발송이 실패하는 등, 이메일만으로 해결이 어려운 경우에 연락드립니다.
  • 청약철회·환불 처리 및 분쟁 시 본인 확인. 결제 건과 구매자가 일치하는지 확인하는 데 사용합니다.

하지 않는 것 — 광고·마케팅 문자나 전화 발송, 제3자 판매·제공, 결제와 무관한 목적의 이용. 번호는 내 계정에서 언제든 수정하거나 삭제를 요청할 수 있습니다.

  • 대금 결제 및 재화 등의 공급에 관한 기록 — 5년 (전자상거래법)
  • 소비자 불만 또는 분쟁 처리에 관한 기록 — 3년 (전자상거래법)

5. 이용자 권리

이용자는 언제든 본인 정보의 열람·정정·삭제·처리정지 및 동의 철회를 요청할 수 있습니다. 이름·연락처 수정과 회원 탈퇴는 내 계정에서 직접 할 수 있고, 그 밖의 요청은 support@audioazpro.com 으로 접수합니다. 요청을 받으면 10일 이내에 처리 결과를 알려 드리며, 법정대리인이나 위임받은 사람을 통해서도 요청할 수 있습니다. 법령에 따라 보관해야 하는 정보는 삭제 요청에서 제외될 수 있습니다.

5-1. Flare Tally 앱(iOS·macOS)이 처리하는 정보

Flare Tally 카메라 탈리 앱은 계정 없이 동작하며 이름·이메일 등 개인정보를 요구하지 않습니다. 실시간 탈리 전달을 위해 다음 정보만 서버(camera-tally.onrender.com)로 전송·일시 보관합니다.

  • 방 코드·카메라 번호 — 어느 방의 어느 카메라에 표시할지 정하기 위해 접속 중에만 사용
  • 기기 식별자(iOS identifierForVendor) — 같은 기기의 중복 알림 등록을 정리하기 위한 익명 식별자. 사용자를 식별하지 않으며 다른 정보와 결합하지 않음
  • 푸시 알림 토큰(Apple APNs) — 앱이 뒤에 있을 때 다이나믹 아일랜드·알림으로 탈리를 갱신하기 위한 토큰. Apple 푸시 서비스로만 전달
  • 서버 왕복 지연(ms) — 호스트 화면의 접속 현황 표시용
  • 알림 설정값(알림·진동·잠금 유지 여부, 앱 언어) — 어떤 알림을 보낼지 정하기 위해 접속 중에만 사용

iOS 앱은 같은 Wi-Fi의 호스트를 찾기 위해 로컬 네트워크 권한을 사용합니다(Bonjour 검색). 이 과정에서 외부로 전송되는 정보는 없습니다.

익명 진단 정보(제품 개선용) — 앱과 호스트는 기본적으로 기기 모델, OS 버전, 앱 버전, 접속 방식(온라인/오프라인), 스위처 종류, 오류 종류(접속 실패·끊김 등)를 익명으로 보냅니다. 기기 식별자는 일부만 해시해 사용하며 이름·계정·이메일·방 코드·IP·위치와 연결하지 않아 특정 개인을 알 수 없습니다. 90일 뒤 자동 삭제되고 제품 개선 외 목적으로 쓰지 않습니다. 앱의 도움말(?) 화면과 호스트 설정의 앱 개선 참여에서 언제든 끌 수 있습니다.

macOS 호스트 앱은 라이선스 확인을 위해 로그인한 AudioAZ 계정의 인증 토큰과 익명 기기 식별자(하드웨어 UUID의 해시)를 중계 서버로 보내며, 서버는 이를 라이선스 조회에만 사용하고 저장하지 않습니다. 데모 사용 시에는 기기 식별자와 데모 시작 시각만 전송됩니다. 계정 로그인 정보(갱신 토큰)는 사용자의 맥에만 저장되며 비밀번호는 저장하지 않습니다. 스위처 IP 등 설정은 맥에만 저장됩니다.

위 정보는 접속(세션) 중 서버 메모리에만 있으며 접속 종료·앱 종료 시 삭제되고, 별도 저장·분석·광고·추적에 사용하지 않습니다. 카메라 권한은 방 QR 코드를 읽을 때만 사용하며 영상은 저장·전송하지 않습니다.

Flare Tally (iOS/macOS) — English summary: The app needs no account and collects no personal data. To deliver tally in real time it sends only the room code, camera number, an anonymous device identifier (identifierForVendor, used solely to de-duplicate push registrations), the Apple push token, round-trip latency and notification preferences to our relay server (camera-tally.onrender.com). Anonymous diagnostics (on by default, switchable off in the app's Help screen and in the host settings): device model, OS version, app version, connection mode, switcher type and error types only, with a partial hash of the device identifier; never linked to a name, account, email, room code, IP or location, deleted after 90 days, and used solely to improve the product. The macOS host app sends the signed-in AudioAZ account token and a hashed, anonymous device identifier to the relay server solely to verify the license (or the demo start time while in demo); the server does not store them. Camera access is used only to scan a room QR code; no video is stored or transmitted. Contact: support@audioazpro.com

6. 개인정보의 안전성 확보 조치

  • 관리적 조치 — 개인정보 처리 권한을 대표와 지정된 관리자로 최소화하고, 관리자 화면은 패스키(생체 인증) 로그인으로만 접근합니다.
  • 기술적 조치 — 모든 전송 구간 암호화(HTTPS), 비밀번호 일방향 암호화 저장, 데이터베이스 행 단위 접근 통제, 결제수단 정보 미보관, 백업 파일 암호화(AES-256) 보관.
  • 물리적 조치 — 데이터는 위탁 업체의 보안 인증을 받은 데이터센터에 보관됩니다.

7. 쿠키 및 브라우저 저장소

AudioAZ는 광고·추적용 쿠키나 외부 방문자 분석 도구를 사용하지 않습니다. 다만 서비스 동작을 위해 브라우저 저장소(localStorage)에 다음 정보를 보관합니다.

  • 로그인 상태 유지를 위한 인증 정보
  • 화면 언어·테마 등 설정값
  • 결제 화면의 구매자 이름·휴대폰 번호(다음 결제 시 자동 입력)와 결제 통화 선택
