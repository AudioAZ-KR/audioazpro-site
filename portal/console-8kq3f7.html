프로모션 코드 발행

생성된 코드 (미리보기)
—

코드 형식 — 라이선스: AZ-{제품}-{종류}-{랜덤} (예 AZ-KV-D14-7K2M9Q = KV 14일 데모) · 할인: AZ-DISC-{할인}-{랜덤} (예 AZ-DISC-20P-8QK3 = 20% 할인, AZ-DISC-W10000-… = 1만원 할인). 할인 코드는 적용 기간(시작~종료) 내에서만 유효. 서버가 발행 DB와 대조해 유효성·사용횟수·기간을 검증합니다.

관리자 계정 생성기 🔒

이 맥의 Touch ID 인증이 있어야만 새 관리자 로그인을 만들 수 있습니다. 생성 버튼을 누르는 순간 애플 패스키(Touch ID) 확인을 거치며, 대표님 애플 기기가 아닌 곳에서는 생성이 차단됩니다.
—

임시 비밀번호는 새 관리자에게 안전하게 전달하고, SALT·HASH는 (백엔드 연결 전) 소스/저장소에 등록해야 실제 로그인으로 동작합니다. 백엔드 연결 후에는 이 생성이 Supabase(App Attest 검증)로 실제 계정을 발급합니다. 비밀번호 원문은 서버·소스에 저장하지 않습니다.
